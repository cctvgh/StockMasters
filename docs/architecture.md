# StockMasters 系统架构详解

## 一、系统定位

一个基于国内数据源的多大师投资分析系统。输入股票代码，十八位投资大师（格雷厄姆、巴菲特、林奇、费雪、芒格、马克斯、索罗斯、达利欧、李录、段永平、张磊、但斌、蒂尔、木头姐等流派）从各自视角独立打分，加权形成共识裁决——买入、持有还是卖出。

核心价值：**纯本地部署 + akshare 国内数据直连 + 企业内网防火墙环境下可用**。

## 二、主要功能

| 功能 | 说明 |
|------|------|
| 个股分析 | 输入代码自动识别市场（A股/B股/港股），十八位大师独立评分，输出综合评分（0-10）、买卖信号、置信度、多空分布 |
| 自选股批量分析 | 添加自选股列表，一键批量分析全部，结果表格展示，支持同步到定时任务 |
| 分析历史记录 | 每次分析自动存档（`data/history.json`），支持按代码/信号/日期筛选，点击记录可重新查看 |
| 定时盘后推送 | 每日指定时间自动分析自选股，通过飞书/企微 Webhook 推送结果报告，服务重启自动恢复定时任务 |

## 五、关键技术设计（受限内网适配）

1. **防火墙降级策略**——东财 `push2his`/`push2` 子域被防火墙拦截后，A股改走 `datacenter.eastmoney.com`（始终可达）、B股改走新浪源、港股改走百度估值

2. **反算估值**——B股无现成 PE/PB 数据时，用 `价格÷年化EPS` 和 `价格÷每股净资产` 从财务数据反算；安全边际大师用**价格近3年分位**替代 PE 分位

3. **稳定性工程**——monkey-patch `requests.Session.request` 全局注入 User-Agent（防风控拒绝）+ 指数退避重试 + 5分钟数据缓存

4. **缓存命中也存档**——分析结果缓存命中时同样写入历史记录，避免历史记录缺失

## 六、API 接口

| 接口 | 方法 | 用途 |
|------|------|------|
| `/api/analyze?code=600900` | GET | 单只股票分析 |
| `/api/batch` | POST | 批量分析 `{"codes":["600900","00700"]}` |
| `/api/history` | GET | 历史记录（可按 code/signal/date 筛选） |
| `/api/settings` | GET/POST | 定时任务设置读写 |
| `/api/cron-status` | GET | 定时任务运行状态 |
| `/api/cron-run` | GET | 立即执行一次 |

## 七、市场识别规则

- 6 位数字且 200/900 开头 → **B股**（深B 200xxx / 沪B 900xxx）
- 6 位数字其他开头 → **A股**（600/000/300/688 等）
- 1~5 位数字 → **港股**（自动补零到 5 位，如 00700）

## 八、典型使用场景
